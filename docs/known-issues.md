# 已知问题

- 兼容补丁按厂商库完整哈希及布局锁定；不支持对任意SDK猜偏移。专用D2驱动副本替换了PID0300枚举项。
- SDK核心仍是闭源第三方库；底层故障可能导致进程崩溃或USB控制器异常，需隔离子进程、期限和独占相机。
- 高清双流已禁止；高清30fps仅USB3单流实验，关闭软件滤波后噪声变化尚需验收。
- 原生库自行重编译后，哈希很可能不同。X5应用示例固定原实测 libd2sdk.so 哈希，不能直接将自行构建库塞入就宣称受支持。先独立运行sdk探针，审阅并验证新构建，再更新本地专用加载清单。
- 出厂参数可以读取，但不是任意输出方向/分辨率的现成内参。实验应用仍含脱敏为D2_SAMPLE_SERIAL的样机绑定，不是通用激活配置；仓库没有默认启用文件。
- IR/深度完整几何对应、曝光时序、真人连续识别、防伪有效性均未通过完整验收。实验分支默认不作为可部署解锁方案。
- RGB人脸已实际解锁，但无活体能力；照片、视频可能冒用，没有量化FAR/FRR、跨用户验证或长期可靠性承诺。保留PIN。
- X5 QML为原UI组件，依赖原工程属性/组件。仓库不包含整套轮椅UI、服务单元或一键部署器。
- Hello COM源取图成功不等于Hello登录可用；stub/INF没有正式签名与认证。
- 历史记录仅代表当轮，最终状态优先读根README和验收摘要。
