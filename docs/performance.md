# 实测性能与已知限制

以下是同一 MX6000/TornadoD2 样机、RDK X5 Linux ARM64 的历史数值，不是所有D2保证。官网的请求尺寸与适配器实际输出尺寸要分开：标准深度请求400×640，原生输出640×400；高清深度请求800×1280，输出1280×800。

| 条件 | 测得帧率 | 说明 |
|---|---:|---|
| USB2 标准深度＋IR | 各约30.16fps | 标准联合模式可用 |
| USB2 高清深度/IR单流 | 约7.25fps | 改请求fps数字不能解决 |
| USB3 高清深度，默认软件滤波 | 约14.53fps | X5主机处理开销 |
| USB3 高清深度，关闭该流软件滤波 | 约30.157fps | 单流、实验；噪声特性改变 |
| USB3 高清IR单流 | 约30.155fps | 单流、实验 |

USB3高清双流曾使原厂驱动超时并伴随USB异常；v0.2.0在配置阶段拒绝所有涉及高清的双流组合。需要联合深度+IR时使用标准模式。USB恢复曾需要重启主机，不能承诺热插拔和长时间运行可靠性。

彩色是独立UVC端点。某轮USB2测试不同模式约2.36–12.61fps，后续更换曝光/采集格式可改善，但未宣称官网所有彩色模式达标。RGB与深度未完成可用的几何配准；不要将RGB检测框直接索引深度。

深度旋转后的原始缓冲区前16字节曾被覆盖；适配器将复制后前8个深度像素置零并设flag，不修改原厂帧，无法恢复丢失样本。调用方检查 flags、真实尺寸、stride、无效值及时间连续性。

相机声明的时间戳与主机接收时间分开保留；主机时间不是曝光时间。硬件同步、绝对曝光年龄、全视场IR/深度对齐和全范围毫米精度未完成验收。功耗、照度、环境温度、认证及FOV未做物理验收。
