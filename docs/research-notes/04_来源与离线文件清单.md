检索覆盖中文型号名、蚂里奥 D2／D2 Pro、D2 OpenNI／Linux／SDK／驱动／PDF 等组合；深入核对了奥比中光官网、蚂里奥官网及官方 GitHub 仓库。新的产品资料下载页主要列当前产品，本次未在其中定位到 D2 专用完整规格书。[当前官方资料入口](https://www.orbbec.com.cn/index/Download2025/info.html?cate=121&id=1)

旧开发者站 `developer.orbbec.com.cn` 多次访问超时；搜索索引可见 OpenNI Linux ARM64 安装说明，但汇总结论使用了可直接取得的官方 GitHub 安装文档。GitHub REST API 当时触发匿名限流，后续通过公开网页和原始文件地址取得资料。ROS 文档站有访问校验，相关规范从 ROS 官方 GitHub 保存。

本机 `tar` 对 ARM64 内层 RAR5 报错的限制已单独列明，未把下载失败页、未知网盘包或未经证实的刷机工具列为有效驱动。
