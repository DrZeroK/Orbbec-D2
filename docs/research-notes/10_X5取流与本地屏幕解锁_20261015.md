## 应用解锁行为

首次使用在触屏上两次设置六位数字 PIN，不预置 PIN，也不通过聊天收集。设置后启用后端保护；服务再启动时默认锁定。日常可点人脸解锁或输入 PIN。人脸录入在“设置 → 密码与安全 → 人脸解锁”，要求已解锁且再次验证 PIN。

PIN 与远程访问码分开保存，使用随机盐、PBKDF2-HMAC-SHA256 600000 次及常量时间比较，创建文件即为 0600。一分钟内五次尝试触发限速。损坏 PIN 文件进入维护状态，不会退回首次设置。人脸模板只保存本机特征向量，文件为 0600，不保存照片或上传云端。

后端统一拒绝锁态本机敏感写操作及访问码读取，保留状态、遥测桥、求助、已有通话及远程原权限。旧长按解锁入口已移除。PIN 不依赖相机；识别超时或模型异常时仍可使用。识别运行于有超时的独立进程，晚到结果不能覆盖后续锁定操作。

YuNet 和 SFace 为固定官方 OpenCV Zoo 提交的完整模型，已核对 LFS 大小和 SHA-256并保留 MIT、Apache 2.0 许可。X5 OpenCV 4.11 的装载及推理 API 已通过合成全零输入检查，不代表真人识别。当前采用五个连续样本、至少 0.5 秒及实验余弦阈值 0.60；需在用户方便拍摄时验收误识和拒识。模型来源与许可（原始归档项）。
