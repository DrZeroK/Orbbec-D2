# X5 深度与红外防照片、视频：候选实现

2026-10-15（Asia/Shanghai）。本轮已完成代码、合成测试和 Qt 离屏检查，**未部署、未重启生产服务**。用户暂不方便纸板对齐或真人测试，因此候选在缺少实测对齐记录时拒绝人脸解锁，保留独立 PIN。当前生产仍为 10 号记录（原始归档项） 中的上一版，不应将下文候选行为当成已上线能力。

## 已实现的必经条件

身份特征改为从 D2 红外图像提取，深度筛查使用同一张红外图像的五点人脸位置，避免把彩色照片外的真实背景误当作脸部深度。两流、身份比对、几何质量及连续帧条件必须全部通过；无深度、权限不足、异常 SDK、对齐未验收或超时均拒绝，不自动退回纯 RGB。

| 条件 | 候选处理 |
| --- | --- |
| 设备、SDK 与对齐 | 唯一 2bc5:060d；固定六个官方运行库/配置 SHA-256；实测空间及时间基准记录为严格 true，设备、模式、镜像和内参匹配 |
| 数据时序 | 两流计数及 SDK 时间戳递增；拒绝相邻重复内容；跨流 SDK 时间差不超过18 ms、主机交付差不超过80 ms、交付年龄不超过250 ms；使用后不复用 |
| 深度区域 | 同一 IR 人脸关键点限定的脸内区域；有效毫米深度覆盖至少90%，鼻/双颊/额头/下脸分别有有效数据，实验距离40–100 cm |
| 平面媒体 | 在相机 XYZ 中拟合平面，检查局部鼻凸；不以整脸深度方差作为通过依据，因此斜放平板也须被拒绝 |
| 弯纸与背景 | 去除平滑二次曲面后再检查鼻部局部凸起及横纵邻域；拒绝深度断边、异常跨度、关键位置深度孔和背景混入 |
| 红外质量 | 按原始0–1023强度实验门槛检查过曝、对比和纹理；实际动态范围仍须实机验收；IR非零本身不代表真人 |
| 身份与连续性 | 实验 SFace 余弦阈值0.60，至少5个连续合格样本、跨度至少0.5秒；失败帧和过大间隔重置，不跨失败累计 |
| 后端门控 | 人脸解锁与录入都要求正确策略号及防伪通过凭证；客户端自行提交 matched/embedding 等字段不能绕过 |
| PIN | 原 PIN 哈希、限速、求助和通话机制保留。人脸请求阻塞时 PIN 仍能完成解锁，晚到人脸结果被 epoch 丢弃 |

红外特征与原 RGB 特征不是同一录入域。候选仅接受 version2、modality=d2-ir-depth-v1 模板，旧 RGB 模板保留在原文件但不会自动转换或使用；未来在对齐验收后，须由用户在解锁状态再次验证 PIN 才能重新录入。没有本次真人模板，也没有预设 PIN 或保存照片。

## 本轮实机观察与未解决的配准

在用户选择仅做代码/合成测试之前，有限时探针同时取得深度、IR各30帧，约1.114秒，未保存图像。SDK请求深度400×640，实际帧及 VideoMode 却为640×400；IR选择640×400后实际同为640×400。两路显式关闭流镜像成功。相同帧号的时间戳有约42 ms偏移，不能当作同一次曝光；最近时间戳配对也不能独立证明曝光同步。原始双流日志（原始归档项）。

官方 ARM64 驱动的静态证据解释了尺寸差异：D2 端帧路径将请求栅格旋转并交换宽高；不能再默认逆转一次深度。其输出首8个 uint16 像素有特殊覆盖，候选明确置为无效。**目前尚未证明深度和 IR 像素一一对应**；没有按同尺寸直接开通人脸。默认只支持经实测确认的 identity 映射，若纸板实测不是 identity，必须新增正确变换并重新验收。

标准 DepthColorSync 面向深度与 OpenNI 彩色流，不能拿它承诺当前 UVC 彩色或 IR 同步；公共 D2C 转换映射到彩色，也不是 DepthToIR。官方通用声明不能替代本机试验。[奥比官方 OpenNI API](https://github.com/orbbec/OpenNI_SDK/blob/main/Doc/English/0400_API.md)、来源与边界清单（原始归档项）。

补充逆向结论：相机参数属性14有专用读取分支，isPropertySupported=false 不足以证明它不可读；后续可直接以120字节读取并检查返回值。本轮未进行该直接读取，也未猜测标定分辨率、平移单位或 IR 映射。REA 证据包括 ev_7363719613ecacc5aefb7a8b83139c879da12db6d7f72bccb312ec0315b79cbd、ev_19834b3dbd4d016054061d65da26b835eaed0fad971a59d0a088f0bfe02f9640、ev_cf14fcfbd4ad2b3076be967979de2197337c9ae07568f987c4999c9662a9e988；官方 driver SHA-256 为24e43298e83d74bb3ce8dcf3ca28979e6334603f9d0534542aa5891cc6764e4b。
