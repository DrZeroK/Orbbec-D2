# 资料清单与公开范围

资料来自原D2项目2026-10-13～15的取流、逆向、SDK适配、Windows Hello、X5人脸、出厂参数和防伪实验。采用复制整理，原工作区未移动、未覆盖，板端未部署或重启。

## 已公开

- ARM64 SDK **v0.2.0最终源码**，C头、原生实现、模式／帧合约、打包器、探针和测试。重复v0.1归档不再重复提交，演进差异见性能说明。
- Win64原始SDK枚举／深度／IR工具、MF COM源、消费者、照明差分实验和UMDF草案。厂商路径和VC构建入口作了便携调整。
- 最新实际解锁通过的RGB-only人脸、PIN、预览代码和相关测试；原完整UI HTTP回归保留在upstream-tests供接入原工程后运行。未混入后来未部署的其他UI改动。
- 最后IR实验分支、共享深度配对／几何防伪代码，以及合成测试。
- 高清、UVC、USB、出厂参数、棋盘标定与时序诊断源码，A4棋盘PDF。原机器隔离采集脚本保留为研究参考，脱敏路径需要自行配置。
- 原01～11号研究笔记、实物首轮研究记录、逆向分析说明、经过脱敏的数值摘要。历史笔记不代表当前功能启用状态。
- 官方参数、产品图片外链、SDK/手册/ROS/模型官方入口、下载文件哈希、第三方许可。

## 未上传及原因

| 类别 | 处理 |
|---|---|
| 官方SDK ZIP/RAR、DLL/SO、驱动安装器、PDF和官网HTML快照 | 再分发授权不明确；保留官方链接、大小和SHA-256，用户自行取得 |
| 修改后厂商库、预编译自研SO/DLL/EXE | 不混发厂商依赖；公开完整自研源码和本地构建方式。可复现构建后自行验证 |
| 真实照片/红外图/深度图、PGM/NPY、截图、视频、人脸模板/PIN/访问码、环境凭据 | 不公开。数值摘要不含身份特征 |
| 真实序列号、私有主机名/IP和Windows账户路径 | 替换为占位符。单机出厂激活文件不提交 |
| 模型权重、venv、依赖发行包、构建缓存 | 官方固定URL、许可和校验下载工具代替复制 |
| 重复stage副本、备份、打包产物、大型REA数据库/反编译快照 | 合并有意义的最终源码，保留分析说明和来源哈希，避免重复及未知第三方权利 |
| 一次性远程上传、sudo部署、服务重启、网络恢复脚本 | 绑定私人环境且不属于相机公共接口；不提供自动覆盖他人机器的入口 |
| 轮椅整套UI/导航/语音和无关个人工程 | 只提取D2相关组件，宿主集成依赖在各目录说明 |

源文件到公开路径的SHA-256映射见 [provenance.json](../evidence/provenance.json)。部分便携路径、默认不保存原始帧、说明文字和测试位置在公开整理时调整；original_sha256与published_sha256保留区别。实验factory夹具仅是脱敏样机参数示例，不能直接用于别的设备。
